# Тренажёр тайского алфавита

Мобильное веб-приложение: 21 урок, все 44 согласные, слова, подсказки по буквам-двойняшкам, тренировка тонов и классов согласных.

## Запуск

```bash
python3 -m http.server 8765
```

Открыть http://localhost:8765 (с телефона в той же сети — `http://<IP компа>:8765`, IP: `ipconfig getifaddr en0`).

Из файла напрямую (`file://`) не работает — браузер блокирует загрузку JSON.

## Структура

- `index.html` — разметка, `style.css` — стили
- `js/` — логика, обычные скрипты в общем глобальном пространстве; порядок подключения в `index.html` важен:
  - `util.js` — `$`, `esc`, `shuffle`, `store` (localStorage)
  - `data.js` — загрузка `data/*.json` (`loadData`)
  - `thai.js` — тайское письмо: отображение знаков, урок слова, тоны по диакритике, нормализация ввода
  - `hints.js` — подсказки при ошибке (двойняшки, подсветка места)
  - `tone-rules.js` — объяснение тона: класс + знак + тип слога
  - `state.js` — общее состояние `S` (урок, вкладка, настройки практики)
  - `layout.js` — уроки, плашка урока, вкладки, Enter
  - `practice.js` — вкладка «Практика»
  - `letters.js` — вкладка «Буквы»
  - `classes.js` — вкладка «Классы»
  - `main.js` — старт
- `data/` — данные: `words.json`, `letters.json`, `patterns.json`, `twins.json`, `lessons.json`, `tones.json`

После правок увеличь `?v=` у скриптов и `style.css` в `index.html`, иначе телефон может показывать старую версию.

Новое слово — одна строка в `data/words.json`: `{"t":"…","r":"…","m":"…"}`. Поле `L` (номер урока) нужно только словам с гласными-сочетаниями.
