# Тренажёр тайского алфавита

Мобильное веб-приложение: 20 уроков, слова, подсказки по буквам-двойняшкам, тренировка тонов.

## Запуск

```bash
python3 -m http.server 8765
```

Открыть http://localhost:8765 (с телефона в той же сети — `http://<IP компа>:8765`, IP: `ipconfig getifaddr en0`).

Из файла напрямую (`file://`) не работает — браузер блокирует загрузку JSON.

## Структура

- `index.html` — разметка
- `style.css` — стили
- `app.js` — логика
- `data/` — данные: `words.json`, `letters.json`, `patterns.json`, `twins.json`, `lessons.json`, `tones.json`

Новое слово — одна строка в `data/words.json`: `{"t":"…","r":"…","m":"…"}`. Поле `L` (номер урока) нужно только словам с гласными-сочетаниями.
